# 创新点一：异构数字 SRAM-CIM Tile 架构探索方法

> 记录日期：2026-08-09
>
> 定位：编译器表征驱动、物理约束感知的异构 Tile 架构与多目标 DSE 方法

## 1. 创新点概述

本文首先使用开源数字 CIM 编译器生成并表征多种规模的 SRAM-CIM Macro。表征结果显示，
随着阵列行数增大，Macro 在满行、高利用率状态下通常能够获得更高的能效比和面效比。
然而，大 Macro 的计算粒度较粗，当输入张量的归约维度、输出通道数或计算形状与阵列规模
不匹配时，会出现大量未使用行或低效映射，导致其理论效率无法在实际网络中充分兑现。

针对“大 Macro 本征效率高，但工作负载适应性弱”这一矛盾，本文提出大小 Macro 协同的
异构数字 SRAM-CIM Tile：使用大 Macro 承载高 K、高复用的规则卷积和投影计算，使用小
Macro 承载注意力、小 K、尾部以及其他低利用率计算，以同时获得较高的阵列利用率和能效。

由于异构 Tile 内应该包含哪些 Macro 类型、每种 Macro 的数量以及如何分工均无法凭经验
直接确定，本文进一步提出面向 CNN 和视觉 Transformer 的异构 Tile 多目标 DSE 方法，
联合搜索物理 Macro 组成和工作负载映射，并在统一硬件约束下评价能量、延迟和面积。

## 2. 待解决的核心问题

不同规模 Macro 之间存在两类相互冲突的特征：

| 特征 | 大 Macro | 小 Macro |
|---|---|---|
| 满利用率能效比 | 较高 | 较低 |
| 满利用率面效比 | 较高 | 较低 |
| 计算粒度 | 粗 | 细 |
| 小 K 或不规则张量利用率 | 较低 | 较高 |
| 映射灵活性 | 较低 | 较高 |
| 外围控制复杂度 | 单一 | 多实例调度开销较大 |

只使用大 Macro 容易在小尺寸张量上浪费阵列资源；只使用大量小 Macro 虽然映射灵活，
却会损失 Macro 本身的能效比和面效比，并增加实例数量、调度状态和外围开销。因此，合理
的 Tile 不是简单选择最大或最小 Macro，而是在本征效率、实际利用率和外围成本之间寻找
折中。

本文需要回答以下研究问题：

> 在给定工艺、精度、频率、算力窗口和 Tile 接口约束下，应该选择哪些规模的 Macro、
> 每种 Macro 配置多少个，并如何将 CNN 和 Transformer 算子映射到这些 Macro，才能形成
> 跨负载稳定的能量-延迟-面积近优 Tile？

## 3. 核心研究假设

本文的核心假设为：

> 大、小 Macro 的异构组合可以利用大 Macro 的高本征效率和小 Macro 的细粒度适应性，
> 在多样化 CNN/Transformer 张量形状下获得比单一规模 Macro 更稳健的能量、延迟和面积
> 折中。

当前重点检验的 Tile 结构是：

```text
1 x 512-row Macro + 1 x 64-row Macro
```

该结构是必须评价的研究锚点，但不得在候选生成、调度剪枝、目标函数或 Pareto 判定中获得
人为优待。DSE 的作用是检验它是否能够从统一候选空间中成为跨工作负载稳健近优组合，
而不是预先保证该结构胜出。

## 4. 方法框架

创新点一形成如下完整方法链：

```text
开源数字 CIM 编译器
    -> 多规模 Macro PPA 表征
    -> Macro 本征效率与利用率矛盾分析
    -> 大小 Macro 异构 Tile 候选空间
    -> CNN/Transformer 工作负载映射
    -> 物理约束感知的能量、延迟和面积评价
    -> Bayesian 候选选择与精确调度评价
    -> 跨网络 Pareto 和 regret 聚合
    -> 稳健近优 Tile 组合
```

### 4.1 编译器表征驱动的 Macro 模型

DSE 不使用理想化的统一 Macro 缩放模型，而是将不同规模 Macro 的编译器表征结果作为
输入，包括：

- Macro 行列规模；
- 输入、权重和输出精度；
- 峰值计算能力和 VMM 周期；
- 满行 VMM 能量；
- Macro 面积；
- 权重行写入能量。

部分行计算采用 Macro 相关的：

```text
E_compute(N_active_rows) = E_fixed + E_rows * N_active_rows
```

模型。每种 Macro 保留其编译器给出的满行动态能量，并使用实验测得的固定/行相关比例
修正部分行能量，避免将未开启行错误地按完全线性比例缩放。

### 4.2 异构 Tile 搜索空间

Tile 允许同构或最多两种 Macro 类型的异构组合。当前候选 Macro 为：

```text
32x8, 64x8, 128x8, 256x8, 512x8
```

所有候选统一限制在以 `0.4608 TOPS` 为中心的 `+-20%` 峰值算力窗口内。候选空间不通过
面积、容量或特定目标结构进行预筛选，面积和容量作为评价输出，用于判断不同组合的实际
资源代价。

### 4.3 物理约束感知的映射模型

DSE 联合考虑以下 Tile 物理约束：

- Tile 固定最多 4 条物理输出 lane；
- 4 lane 对应 32 个输出/psum 寄存器和 32 个输出端口；
- 特征入口带宽为 512 bit/cycle，权重入口带宽统一为 64 bit/cycle；两类传输时序互斥；
- 同一周期只能传输特征或权重，不能同时传输二者；
- 同一个 Macro 同一时刻只能执行一个 VMM；
- 同 wave 多 Macro 归约和跨 wave psum 加法计算动态能量；
- 跨 wave psum 保存在 Tile 输出寄存器中；
- 闲置 Macro 不产生动态计算能量，但仍支付静态功耗；
- Macro 可以按实际张量 K 维只开启部分阵列行。

这些限制使搜索结果对应可实现的 Tile 数据通路，而不是只根据 Macro 峰值 TOPS/W 进行
理想化组合。

### 4.4 CNN 与 Transformer 联合评价

对于 CNN，DSE 搜索卷积/全连接层在 Macro、K-wave 和输出 lane 上的映射，并按层顺序
聚合完整网络的能量和延迟。

对于 Transformer，Tile 内物理 Macro 被划分为投影 bank 和注意力 bank：

- 投影 bank 执行 Q、K、V、O 以及 FFN 投影；
- 注意力 bank 执行 `QK^T` 和 `Attention x V`；
- 两个 bank 共享 4 lane、512-bit特征入口和64-bit权重入口；
- 搜索器同时评价两种 Macro 的角色方向，不预先指定 512 Macro 必须执行投影；
- 稳态流水延迟由投影、注意力和共享总线三个路径的最大值决定。

该映射用于检验异构 Macro 是否能够针对不同算子形状形成空间分工，而不是把整个网络
始终映射到同一种 Macro。

### 4.5 多目标搜索与跨网络判定

外层搜索使用 Bayesian 方法从理论候选空间中选择需要实际评价的 Tile，内层使用带状态
上限的 Pareto 调度搜索获得每个 Tile 的合法映射。Bayesian Optimization 本身不是本文
的算法创新，它用于减少昂贵架构评价次数。

本文的方法贡献在于建立编译器表征、部分行能量、物理接口、异构映射和跨网络目标之间的
统一评价问题。最终同时报告：

- 能量-延迟 Pareto；
- 能量-面积 Pareto；
- 能量-延迟-面积 Pareto；
- 各候选到 Pareto 前沿的 regret；
- 跨网络通过率、中位 regret 和最坏网络 regret。

## 5. 与普通 DSE 工具的区别

本文不应把创新点描述成“实现了一个 Python 搜索工具”。普通搜索工具只负责枚举参数或
调用标准优化算法，而本方法解决的是异构 CIM Tile 特有的架构-映射联合问题：

1. 搜索变量同时包含物理 Macro 组成和算子映射，而不是只调整软件参数；
2. 成本模型来自多规模 CIM Macro 的编译器表征和部分行实验数据；
3. 约束对应共享总线、lane、寄存器、psum 和 Macro 互斥执行等真实硬件资源；
4. 同一 Tile 在 CNN 与 Transformer 中使用不同映射和流水方式；
5. 候选通过跨网络 Pareto 稳健性而不是单个网络的单一目标选出。

因此，该创新更准确的名称是“异构数字 SRAM-CIM Tile 架构探索方法”或“编译器表征驱动
的异构 CIM 架构-映射协同 DSE”，搜索器只是该方法的实现载体。

## 6. 创新成立所需的实验论证

当前四项基础实验的定义、复现命令和数据覆盖情况记录在
`paper/innovation1_experiments.md`。

### 6.1 Macro 规律验证

- 展示不同规模 Macro 的满行 TOPS/W 和 TOPS/mm2；
- 展示活动行数变化时的实测或校准能量；
- 展示大 Macro 在不同 K、N 和张量形状下的利用率下降；
- 证明只比较满行 TOPS/W 无法正确选择网络级 Tile。

### 6.2 架构对照

至少评价以下结构：

```text
1x512
9x64
2x256
4x128
1x32 + 1x512
1x64 + 1x512
1x128 + 1x512
```

其中，`1x512` 用于证明加入小 Macro 的价值，`9x64` 是严格等算力同构基准，
`32+512`、`64+512` 和 `128+512` 用于证明辅助 Macro 粒度的选择依据。

### 6.3 搜索方法验证

- 在可穷举的缩小空间中比较搜索结果和完整穷举前沿；
- 报告 Pareto recall、最终 regret 和遗漏候选数量；
- 与随机搜索、规则网格搜索或标准单目标 BO 比较评价次数和运行时间；
- 证明搜索剪枝不会系统性排除小 Macro 密集结构；
- 对超时候选给出完成评价或不能支配目标结构的保守边界。

### 6.4 消融实验

- 移除部分行能量模型；
- 忽略闲置 Macro 静态功耗；
- 忽略共享总线限制；
- 关闭 Transformer 投影/注意力流水；
- 固定或交换两个 Macro 的任务分工；
- 去除面积目标，仅比较能量和延迟。

这些实验需要说明每一项物理模型如何影响最终 Tile 排序，从而证明完整 DSE 方法的必要性。

### 6.5 跨网络验证

建议覆盖标准 CNN、轻量 CNN、轻量 Transformer、混合 Transformer、分层 Transformer
以及大型压力测试。每个网络使用相同候选面板、硬件约束和模型版本，并实际评价所有纳入
跨网络统计的候选。

`64+512` 是否为稳健近优结构，应依据预先冻结的单网络 regret、跨网络通过率、中位
regret、最坏 regret 和 Pareto 命中率共同判断，不能只展示有利网络或单一目标。

## 7. 创新边界

本文没有提出新的通用 Bayesian Optimization 算法，也没有重新搜索 SRAM bitcell、
数据精度或器件工艺。创新范围限定为：

- 多规模数字 SRAM-CIM Macro 的组合；
- Tile 内异构 Macro 分工与映射；
- 编译器表征和实验校准驱动的成本模型；
- 物理 Tile 约束下的多目标搜索；
- CNN/视觉 Transformer 跨负载稳健性评价。

当前固定面板只实际评价 Bayesian 选择的 48 个候选，因此在没有补充完整穷举或严格代理
误差界之前，结论必须限定为“48 个实测候选中的稳健近优结构”，不能宣称是全部 138 个
理论候选中的唯一全局最优。

## 8. 可用于论文贡献列表的表述

建议将创新点一概括为：

> 针对大规模数字 SRAM-CIM Macro 满利用率效率高但张量适应性不足的问题，本文提出一种
> 大小 Macro 协同的异构 Tile 架构探索方法。该方法以开源 CIM 编译器生成的多规模 Macro
> PPA 和部分行能量表征为基础，联合考虑共享数据总线、输出 lane、psum 存储、静态功耗及
> CNN/Transformer 异构映射，在统一算力窗口内执行能量-延迟-面积多目标搜索，从而选出
> 跨工作负载稳健近优的 Tile 组合。

更简短的贡献表述为：

> 提出一种编译器表征驱动、物理约束感知的异构数字 SRAM-CIM Tile 多目标 DSE 方法，
> 通过联合搜索 Macro 组成与 CNN/Transformer 映射，解决大 Macro 本征效率与实际张量
> 利用率之间的矛盾。
