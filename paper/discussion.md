# Tile 级 DSE 论文论证讨论

> 记录日期：2026-08-05

## 1. 论文研究命题

论文使用的 Tile 结构为：

```text
1 x 512-row Macro + 1 x 64-row Macro
```

面向的应用范围为 CNN 和视觉 Transformer 边端侧推理。DSE 需要支持的严谨命题应为：

> 在统一工艺、接口、面积计费和 `0.4608 TOPS +/-20%` 算力窗口下，
> `1x512 + 1x64` 是面向 CNN 和视觉 Transformer 的跨负载稳健近优 Tile 之一。

不应将论文结论表述为“该结构在所有负载上都是唯一全局最优”。工程研究中的“合理”
应由跨负载 Pareto 表现、regret、面积代价和模型敏感性共同证明。

## 2. 当前 ViT v5 结果提供的证据

当前 ViT-B/16 v5 结果中，`1xm64x8+1xm512x8`：

- 不属于纯能量-延迟 Pareto 集；
- 属于能量-面积 Pareto 集；
- 属于能量-延迟-面积 Pareto 集。

关键对照如下：

| 对照结构 | `64+512` 的相对表现 |
|---|---|
| `128+512` | 能量高约 `0.38%`，延迟高约 `0.02%`，面积低约 `9.3%` |
| 单个 `512` | 能量低约 `3.1%`，延迟低约 `12.9%`，面积增加约 `12.6%` |
| 等算力 `9x64` | 能量低约 `44.4%`、EDP 低约 `17.1%`、面积低约 `1.4%`，但延迟高约 `49%` |

这组结果表明，`64+512` 的主要价值不是取得绝对最低延迟，而是形成适合边端部署的
能量、延迟与面积折中：

- 512-row Macro 负责高 K、高复用的卷积或投影计算；
- 64-row Macro 负责注意力、小 K、尾部和低利用率计算；
- 相比 `128+512`，仅付出约 `0.4%` 的能量代价，即可节省约 `9.3%` 的面积；
- 相比单个 `512`，加入 `64` Macro 能降低能量并缩短延迟；
- 相比严格等算力的 `9x64`，异构结构显著降低能量和 EDP，但放弃部分最低延迟性能。

因此，论文更适合使用“跨负载稳健的 E-T-A 近优结构”作为核心论点，而不是只强调
纯能量-延迟最优。

## 3. 当前尚未闭环的问题

### 3.1 CNN 结果版本不一致

CNN 网络需要使用当前 v5 Macro 能量模型重新评价。旧版本 CNN 结果不能与 ViT v5
结果直接合并计算跨网络 regret，也不能作为最终论文证据。

### 3.2 ViT 候选评价不完整

当前 ViT 固定面板包含 48 个候选，但有 10 个候选因单点评价超过 600 秒而被跳过，
实际完成 38 个。直接排除超时点可能遗漏能够支配 `64+512` 的小 Macro 密集组合，
从而产生有利于目标结构的搜索偏差。

最终结论前，需要完成这些候选的可靠评价，或者给出足以证明它们不能支配目标结构的
保守上下界。不能把“搜索困难”直接视为“架构性能较差”。

### 3.3 边端工作负载代表性不足

ViT-B/16 可以作为计算压力测试，但不能单独代表边端视觉 Transformer。论文还需要覆盖
更典型的轻量化或分层 Transformer。

### 3.4 模型假设需要敏感性验证

当前模型暂不计共享总线能量，并采用：

```text
T_transformer = max(T_projection, T_attention, T_bus)
```

作为稳态流水延迟。Softmax、LayerNorm、GELU、残差加法以及流水填充/排空开销也未计入。
由于 `64+512` 的优势与异构流水密切相关，论文需要报告总线能量、流水效率和非 CIM
开销变化时的敏感性，或者明确将其列为研究边界。

### 3.5 48 点面板的结论边界

当前 48 个候选最初由 Bayesian 优化选择，并不是对 138 个理论候选的完整穷举。因此，
最终结论必须限定为：

> `64+512` 是 Bayesian 实际评价的 48 个候选中的跨负载稳健近优结构之一。

除非后续补充完整穷举或具有可靠误差界的代理模型证明，否则不能将结论外推为整个
138 点空间中的严格全局最优。

## 4. 必须包含的结构对照

| 对照结构 | 需要回答的问题 |
|---|---|
| `1x512` | 增加一个小 Macro 是否真正产生收益 |
| `9x64` | 与 `64+512` 严格等算力的同构结构相比是否合理 |
| `2x256`、`4x128` | 其他同构粒度的能量、延迟和面积折中 |
| `32+512` | 更小辅助 Macro 是否面积更优但性能不足 |
| `128+512` | 更大辅助 Macro 的微小性能收益是否值得面积代价 |
| 关闭异构流水 | 收益有多少来自投影和注意力并行 |
| 交换 Macro 分工 | 映射结果是否由搜索得到，而不是人为指定 |

其中，`32+512`、`64+512` 和 `128+512` 的直接比较是证明辅助 Macro 选择 64 行而不是
任意小 Macro 的核心消融实验。

## 5. 建议的工作负载矩阵

为了覆盖不同的计算形态，建议至少使用：

| 类别 | 建议网络 | 主要覆盖特征 |
|---|---|---|
| 标准 CNN | ResNet-18、ResNet-50 | 规则卷积和不同网络深度 |
| 轻量 CNN | MobileNetV2 | depthwise 与 pointwise 卷积 |
| 高效 CNN | EfficientNet-B0 | 混合卷积尺度和边端部署 |
| 轻量 Transformer | DeiT-Tiny | 典型小型全局注意力 |
| 混合 Transformer | MobileViT-XS 或 Small | CNN 与 Transformer 混合计算 |
| 分层 Transformer | Swin-Tiny | 窗口注意力和分层 token 数 |
| 压力测试 | ViT-B/16 | 大规模投影和全局注意力 |

相比单纯增加同类网络数量，该矩阵能够分别验证规则卷积、低利用率计算、投影、全局
注意力和窗口注意力下的结构合理性。

## 6. 冻结判断标准

继续使用当前已经冻结的跨网络标准：

| 判定项 | 阈值 |
|---|---:|
| 单网络联合 regret | `<= 5%` |
| 跨网络通过率 | `>= 80%` |
| 跨网络中位 regret | `<= 3%` |
| 最坏网络 regret | `<= 10%` |
| 严格命中 E-T 或 E-T-A Pareto 的网络比例 | `>= 50%` |

每个网络应同时报告：

- `r_ET`；
- `r_ETA`；
- 联合 regret；
- E-T、E-T-A 和 E-A Pareto 成员资格；
- 最小能量、最小延迟、最小 EDP 及排名；
- Tile 面积、峰值算力和关键资源利用率。

只要 `64+512` 满足全部跨网络阈值，就足以支持“跨负载稳健近优”的论文论断，
不要求它在每个网络上都取得最低能量或最低延迟。

## 7. 推荐的最终论文结论形式

如果实验结果满足冻结阈值，可采用类似如下的结论：

> 在 22 nm、400 MHz、8-bit 数字 SRAM-CIM 和统一 512-bit Tile 总线条件下，
> `1x512+1x64` 在 Bayesian 实际评价的固定候选面板中，对 CNN 与视觉 Transformer
> 工作负载表现为稳定的能量-延迟-面积近优结构。其大 Macro 保持高复用算子的计算
> 效率，小 Macro 减少注意力和低 K 算子的阵列浪费；相比更大的异构辅助 Macro，
> 该结构以很小的能量/延迟代价降低面积，并在多数网络上命中或接近 Pareto 前沿。

该表述能够反映 DSE 实际支持的证据，同时避免超出搜索范围地宣称唯一或全局最优。
