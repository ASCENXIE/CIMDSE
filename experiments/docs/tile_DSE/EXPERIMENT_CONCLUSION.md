# 四网 Tile DSE 实验结论

在 ResNet-18、ViT-B/16、VGG-16 和 ViT-L/16 共同评价的 48 个 Tile 中，**`64+512` 的四网联合 EDAP 最低，得分为 1.054288，比第二名 `1×512` 低 5.38%。** 与第二名相比，`64+512` 在两款 CNN 上的降耗和提速抵消了增加小 Macro 的面积代价，使 CNN 上的 EDAP 收益超过两款 ViT 上的 EDAP 损失。该结论采用 250 MHz 单 Tile 模型，整网调度按当前评价规则回放与校验。 [四网排名 CSV](../../results/tile_DSE/v5/pareto_review_20261120/joint_ranking.csv) · [实验规范](TILE_DSE_EXPERIMENT_SPECIFICATION_V5.md)

## 评价口径

`64+512` 由一个 64 行 Macro 和一个 512 行 Macro 组成，两者均为 8 列，峰值算力为 0.288 TOPS。四网共用同一组 48 个候选，累计完成 **192/192 项整网模型评价**。各入表项均通过 600 秒端到端准入，时间包含搜索、回放、校验和产物哈希。此处的模拟延迟是模型中一次推理的时间，软件运行时间另计。候选由开发双网选出，再将同一组候选用于 VGG-16 和 ViT-L/16。 [联合搜索与终态审计](JOINT_SEARCH_RESULTS.md) · [搜索方法](SEARCH_METHOD.md)

每个 Tile 在每网的已验证调度中取最低 `EDAP = E × T × A`，三个量均来自同一条调度。令 `z` 为该值除以本网络在 48 个 Tile 中的最低 EDAP，四网得分为四个 `z` 的等权几何平均，分数最低者入选。单网差距和 Pareto 前沿用于解释取舍。 [实验规范第 6 节](TILE_DSE_EXPERIMENT_SPECIFICATION_V5.md#6-指标与通过标准)

## 收益与代价来自哪里

### CNN 的主要收益来自合并部分 K 波次

两款 CNN 的代表层 T1 都是 `3×3` 卷积，输入通道数为 64，归约长度 `K = 576`。`64+512` 的获胜调度在同一 lane 将两种 Macro 沿 K 维协作，一次波次覆盖 576 个输入，并执行跨 Macro 归约。`1×512` 需要两个波次，回放中出现了中间部分和的读写。在 T1，`64+512` 把 ResNet-18 的层延迟从 1.869 ms 降到 0.959 ms，把 VGG-16 的层延迟从 29.099 ms 降到 14.619 ms。 [ResNet-18 T1 回放](../../results/tile_DSE/v5/e04_development48_250mhz_bus4_20261117/1xm64x8+1xm512x8/resnet18/representative_replay.json) · [VGG-16 T1 回放](../../results/tile_DSE/v5/vit_l16_budget_recovery_20261119/optimized/panel/1xm64x8+1xm512x8/vgg16/representative_replay.json)

整网比较中，`64+512` 相对 `1×512` 的本地面积增加 18.12%。ResNet-18 的延迟下降 23.88%，能量下降 7.40%，EDAP 下降 16.75%。VGG-16 的延迟下降 20.95%，能量下降 4.22%，EDAP 下降 10.57%。两网账本中，每方向的部分和传输位数分别下降 34.80% 和 38.52%。这些差异支持 K 波次和部分和搬运是 CNN 收益的重要来源。整网差异反映 Macro 组成、峰值算力和调度共同变化后的配置收益。 [逐调度成本及回放来源](../../results/tile_DSE/v5/pareto_review_20261120/points.csv)

### ViT 上的算子分工减少了计算开销，搬运和面积决定净收益

在两款 ViT 的获胜调度中，`64+512` 都用 512 行 Macro 执行投影和 FFN，用 64 行 Macro 执行 `QKᵀ` 与 `AV`，查询块和 KV 块均为 192。`1×512` 由同一个 Macro 串行承担这些角色。ViT-L/16 上，采用这种分工的 `64+512` 相对 `1×512` 的延迟下降 10.78%、能量下降 0.94%，但 18.12% 的面积增幅使 EDAP 高出 4.40%。 [ViT-B/16 回放](../../results/tile_DSE/v5/e04_development48_250mhz_bus4_20261117/1xm64x8+1xm512x8/vit_b16/best_replay.json) · [ViT-L/16 回放](../../results/tile_DSE/v5/vit_l16_budget_recovery_20261119/optimized/panel/1xm64x8+1xm512x8/vit_l16/best_replay.json) · [逐调度成本及回放来源](../../results/tile_DSE/v5/pareto_review_20261120/points.csv)

ViT-B/16 上，`2×256` 的调度让两个等大的 lane 分担输出通道，账本中的输入特征 GB 读事务约为 `64+512` 的一半。`64+512` 相对 `2×256` 少用约 0.447 mJ 的 Macro 动态能量，但总线与 GB 动态能量合计多用约 0.394 mJ，整网能量差距缩小到 1.34%。`64+512` 的延迟和本地面积分别增加 9.19% 和 9.85%，最终 EDAP 高出 18.34%。这一对照表明，Macro 动态能量的节省会被特征搬运成本部分抵消，延迟和面积仍可主导 EDAP 排名。 [ViT-B/16 `2×256` 回放](../../results/tile_DSE/v5/e04_development48_250mhz_bus4_20261117/2xm256x8/vit_b16/best_replay.json) · [开发网排名 CSV](../../results/tile_DSE/v5/e04_development48_joint_ranking_20261118/joint_ranking.csv)

### 面积解释了 ViT 上的 Pareto 位置

`64+512` 在四网均命中能量–延迟–面积（E–T–A）前沿，在两个 CNN 也命中能量–延迟（E–T）前沿。两款 ViT 的最近 E–T 前沿点都是 `128+512`。`64+512` 相对该点的能量和延迟差距最大为 0.2306%，本地面积少 9.71%。计入面积后，`128+512` 的能量与延迟优势不足以在三个维度上同时占优。这里的 0.2306% 是到相应 Pareto 前沿的最小逐维差距，18.34% 则比较 ViT-B/16 上两条调度的 `E × T × A`，分别回答前沿接近程度和单网 EDAP 代价。 [Pareto 复核与调度证据](PARETO_RESULTS.md)

## 结论的适用范围

- **候选与负载。** 联合第一适用于当前共同实测的 48 个 Tile 和四个网络。候选由有界搜索选出，其中两网参与选点，所以这项实验支持面板内选型。对完整 134 个候选空间、全部合法映射或新网络的结论需要额外实验。 [搜索方法](SEARCH_METHOD.md)
- **硬件计费。** 实验采用 22 nm、0.72 V、250 MHz、W8A8 和充分外部服务的单 Tile 口径。EDAP 的面积是 Tile 本地面积，能量含 GB 和总线动态搬运。部分行能量采用外推模型，非 CIM 算子按理想外部服务处理。行缓冲在当前模型中记录供数时间和容量需求。 [实验规范](TILE_DSE_EXPERIMENT_SPECIFICATION_V5.md) · [Macro 表征](../SRAM_DATA/MACRO_CHARACTERIZATION_2026-11-16.md) · [行缓冲模型边界](PARETO_RESULTS.md#cnn-行缓冲核验)
