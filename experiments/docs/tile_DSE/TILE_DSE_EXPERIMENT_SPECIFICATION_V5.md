# Tile DSE现行规范

更新于 2026-11-20。现行协议标识为 `tile_experiment_spec_v5_2026_11_14_kv_state_250mhz`，频率为 250 MHz。
预算和算法见[搜索方法](SEARCH_METHOD.md)，成本来源见 [Macro 表征](../SRAM_DATA/MACRO_CHARACTERIZATION_2026-11-16.md)，后续实验与性能回归要求见[交接记录](../../../HANDOFF.md)。

## 1. 研究范围

检验既定实现 `64+512` 能否在共同实测候选上取得四网联合 EDAP 最优，并解释计算、输入复用、部分和、延迟和面积之间的取舍。
评价对象是单Tile在充分外部服务下的CIM计算与参考访问成本，不是完整芯片端到端PPA。

| 网络 | 用途 | 固定形状，batch=1 |
|---|---|---|
| ResNet-18 | 联合选点与整网评价 | 输入 224×224×3，逐层几何见负载 JSON |
| ViT-B/16 | 联合选点与整网评价 | 192 tokens，hidden768，12 heads×64，MLP3072，12 blocks |
| VGG-16 | 固定候选整网评价 | 输入 224×224×3，13 个卷积层和 3 个全连接层 |
| ViT-L/16 | 固定候选整网评价 | 192 tokens，hidden1024，16 heads×64，MLP4096，24 blocks |

CNN仅支持dilation=1。非CIM算子，包括BN/激活/池化、LayerNorm/GELU/残差和softmax，
按零时间、零能量外部服务处理，但保留依赖和张量形状；CIM接口承担的搬运仍计费。

## 2. 物理候选和资源

22 nm、0.72 V、250 MHz，W8A8，Macro为32/64/128/256/512×8，完整VMM为8周期/32 ns。
每Tile只使用1–2种Macro，组成跨层/网络固定；允许按层重分组或闲置。

```text
peak_TOPS = .016*n32 + .032*n64 + .064*n128 + .128*n256 + .256*n512
.2304 <= peak_TOPS <= .3456
```

理论池138项。依用户限制，实际可选池134项：只排除纯m32数量15/17/19/21，异构中奇数m32合法。
不另按面积、容量或实例数淘汰；主报告覆盖全窗口，严格0.288 TOPS实测子集另作等算力对照。
本轮选点使用准备阶段冻结的 [134 点可选池](../../results/tile_DSE/v5/preparation_250mhz_bus4_development_20261117/candidates_134.csv)。

- 安装输出lane数`L=min(4, Macro数)`；每Macro有双组8-bit输入寄存器，每lane有8个25-bit输出寄存器。
- 每lane另有8×32-bit部分和单缓冲，32 B/lane；64+512共64 B，4×128共128 B，计面积与实际访问能量。
- 每个物理Macro同一时刻只执行一种任务，权重加载与VMM互斥；权重覆盖后恢复必须重新付费。
- 同lane可沿K协作归约，不同lane沿N并行。任务可分阶段换角色，切换控制本身理想化，重载/搬运/等待仍计费。

| 本地通路 | 带宽 | 关系 |
|---|---:|---|
| 投影入口 | FEATURE512、WEIGHT64 bit/cycle | 两模式互斥；CNN、投影、O和FFN使用 |
| 注意力入口 | FEATURE512、WEIGHT64 bit/cycle | 与投影入口独立；QK与AV共用，内部模式互斥 |
| 输出/psum | 256 bit/cycle | 全Tile共享；读、写、最终输出及KV更新互斥，与入口独立 |

一个Macro不能叠加两套入口带宽。作为权重写入的动态注意力操作数走WEIGHT路径。

## 3. 存储和部分和

GB外部容量/服务带宽充分，不施加容量、bank划分或全局1RW仲裁停顿；仍约束上述本地通路。
12×32 KiB、512-bit参考GB用于访问计费和需求报告，不代表已实现充分服务。
外部补入时间/能量不计；实际GB读写、总线和Macro权重写入计入。

- GB每512-bit读22 pJ、写33.6 pJ，已是完整动态成本，不再加地址能量或bankscale。
- 总线为4级512-bit串联寄存器，每笔有效数据穿过全部4级，独立于另计费的Macro输入寄存器。
  按`hwcomponents_library==1.0.58`的22-nm `AladdinRegister`估算，每级每512 bit读、写各1.55959159007 pJ；
  全链路`4*(E_read+E_write)=12.47673272056 pJ/512 bit`，等效0.024368618594836508 pJ/有效bit。
  不再收取router代理成本，也不按64/256-bit通路宽度再次缩放；保留有效bit计费，不额外收取未使用位。
  这是寄存器访问能量模型，不是含时钟树/布线的实测互联功耗；本次不改变带宽、服务周期或添加4周期延迟。
- 输出/psum固定[P,N]行主序，N补齐八通道。仅同位置、连续合法N块可按实际512-bit地址字边界合并；
  不跨位置缓存打包，读写不合并。各Macro权重加载独立取整，不推断跨Macro地址连续性。
- 跨K波次部分和为32 bit，最终输出8 bit，本地输出25 bit。读旧状态可与VMM重叠，累加等待两者；
  累加/首波次转存计1周期。结果进入32-bit暂存后写回可与下一位置VMM重叠，暂存排空前不可覆盖。
- 跨波次每值计两读两写，其中累加更新写已包含在累加器成本，不重复收费。
  首波次暂存每值一写一读；同批混合最终输出/中间结果时统一暂存活跃lane，首波次全部完成才允许8-bit旁路。

每笔总线按实际bits计能量，按对应带宽向上取整服务周期；GB按实际地址事务计数，不能将全网bits统一除512。
分别报告feature、weight、psum-read/write、final-output的逻辑量、bits、事务、周期和能量，避免重复计费。

## 4. CNN映射

K可任意切分，但切片须恢复真实卷积坐标。每个输出通道轮次和后续K-wave重新从图顶扫描；
同一wave广播按真实输入索引去重，接收寄存器分别收费，不假设跨轮次保留整图。
3×3使用两行line buffer与滚动窗口；其他核在线im2col旁路，不把展开矩阵写回GB。
Padding零本地产生，不读GB/总线；没有默认零跳过能力，实际执行仍计计算时间/能量。

GB→line buffer和line buffer→Macro为独立可并行512-bit/cycle通路，后者仍受投影入口模式互斥。
两组行SRAM各1R1W，不能增加第三行；当前行仅用窗口寄存器。覆盖旧行前必须完成消费。
每扫描上下文两行容量为`2*输入宽度*本wave所需通道并集`字节；独立异构上下文容量相加，
候选物理配置取两种CNN全部层/波次需求最大值，跨层固定。line buffer面积/访问能量单列，供数时间仍计入。
当前评价记录供数时间与行缓冲容量需求。本体成本及逐字覆盖校验的模型边界见[行缓冲核验](PARETO_RESULTS.md#cnn-行缓冲核验)。

CNN可同步广播或异构组独立推进，始终共享真实带宽；有限生成语法每映射最多两种lane签名。
不同签名枚举全部正整数N-block总量划分，同签名副本均分，允许闲置；不声称穷举所有映射。
架构通道配额仅约束同时活跃lane，保持原始完整P/K/N工作量：

```text
Ktile = min(每活跃lane协作Macro行数之和); B = ceil(N/8)
l = 0; L = min(4, Macro数)
每级G = 4/2**l; 将B个块整数均分为b[0:G]; Kcover = 4*2**l*Ktile
仅当l<2且max(b)<L且Kcover<K时升一级并重算
active_lanes <= min(L, max(b)); 剩余K由原evaluator完成
```

相等即停止；不能以Kcover模拟跨Tile加速或除以16。该配额用于balanced CNN，不应用于ViT。

共同入口在有界加权搜索后，保留“先代表层、再补齐全部层”的校准顺序，复用已完整回放的映射与证据；
修正后重选整网E-T前沿路径，直到所选路径全部对应完整测量。
E/T和访问/能量/容量账本均取同一完整回放，不以采样误差阈值替代完整层成本；通用单候选诊断的代表层模式不进入共同panel。
每个评价任务最多使用 4 个层进程。软件可并行评价不同层，模拟硬件按串行 CIM 层执行并汇总成本。

## 5. ViT映射与KV状态

每head全部Q/K/V就绪后才能开始该head注意力；允许不同head在互斥Macro分区流水，或全Tile串行。
QK/AV可用不同Macro类型；O/FFN可全Tile协作。按真实依赖计填充、排空和空隙，不能用阶段最大值代替全图。
`Bq,Bk∈{32,64,128,192}`：QK的K=head维度64，AV的K=Bk；尾块按真实形状处理。
异构组按算子不均匀分配并独立推进；同形组保留合法广播，不复制入口或输出带宽。

softmax状态/运算、重缩放和外部加法理想化；跨KV的输出累加状态为32 bit，驻留GB：

| AV阶段 | 共享输出/psum通路服务 | GB访问 |
|---|---|---|
| 只有一块 | 写8-bit结果 | 写最终结果 |
| 多块首块 | 写32-bit状态 | 写状态 |
| 中间块 | 转发当前32-bit结果→读旧32-bit状态→写32-bit更新 | 一读一写 |
| 末块 | 转发当前32-bit结果→读旧32-bit状态→写8-bit结果 | 一读一写 |

转发不额外落GB；后续AV等待前一状态写回，内部K-wave部分和另计。外部更新寄存器不提供整块输出免费缓存。
B块、V个含八通道补齐的输出值：状态读/中间写各`(B-1)*V*32` bit，转发同量，最终写`V*8` bit。

## 6. 指标与通过标准

```text
E = Macro动态 + 全Tile静态功率*T + 输入/输出寄存器 + 跨Macro归约/跨波次累加
  + 部分和暂存访问 + 权重写入 + 总线 + GB动态
A = sum(Macro面积 + 2*rows*8-bit寄存器面积) + 8*L*(25-bit输出寄存器面积 + 32-bit暂存面积)
Q(c,w) = min_实际合法调度(E*T*A)
z(c,w) = Q(c,w)/min_共同实测panel(Q(*,w)); r_EDAP = z-1
G(c) = exp(mean_网络(log(z(c,w))))
```

Macro满行能量按95%动态、5%静态拆分；所有已安装Macro在完整执行时间内含闲置付静态成本，不按VMM重复收费。
主EDAP不含GB/VPU/line buffer/互联/控制面积、GB静态、非CIM运算和外部补入；line buffer成本单列。
各网络等权，E/T/A必须来自同一调度；功耗可另报E/T，不能代替能量。

四网联合最优是唯一的 Tile 选择判据。在 ResNet-18、ViT-B/16、VGG-16、ViT-L/16 共同实测的 48 个 Tile 中，`64+512` 的 `G(c)` 达到最低值即满足判据。各网 `z` 与 `r_EDAP` 用于报告。分数相同的 Tile 共享最低值，展示顺序按设计标识排列。

E–T、E–T–A 近优统计用于说明取舍。令 F 为共同实测面板的相应前沿，S 为实际保留调度。
`r_Q=min(s∈S,f∈F_Q) max(q∈Q) max(0,s_q/f_q-1)`；`r=max(r_ET,r_ETA)`。

| Pareto 诊断指标 | 参考值 |
|---|---:|
| 单网近优 | r≤5% |
| 跨网近优率 / 中位 r / 最坏 r | ≥80% / ≤3% / ≤10% |
| 严格命中E-T或E-T-A前沿的网络比例 | ≥50% |

对四网同时列出前沿命中、逐网近优和跨网汇总，用于解释联合 EDAP 排名。
最终支配容差为相对1e-9：全维不劣且至少一维改善超过容差才支配；并列保留身份，阈值用未舍入值。
结论限于同一模型下共同实测候选和这四网，不能外推全局最优、盲测泛化或量化精度。

## 7. 外层选点与交付

选点在冻结的 134 点可选池上进行，按五维 Macro 实例数归一化特征，随机种子为 7。

- 初始 20 点包含全部 10 个合法同构配置、`32+512`、`64+512`、`128+512`，以及 7 个严格等于 0.288 TOPS 的分层覆盖点。
- 之后以 ResNet-18 和 ViT-B/16 的等权几何平均归一化 EDAP 为目标，选 5 批、每批 4 个期望改进（EI）点。最后选 8 个预测验证点，先取预测联合 EDAP 最低的 4 个，其余优先选预测 E–T–A 前沿代表点，前沿点不足时按预测联合 EDAP 补齐。两个开发网都完成的评价才进入模型拟合。
- 已结案批次用 `run_e04.py --development-only` 完成开发组选点，再用 `run_vgg16_vit_l16_panel.py` 在 VGG-16 和 ViT-L/16 上评价同一组 48 点。最终按第 6 节用四网整网回放结果评分。 [运行入口](../../RUN/tile_DSE/v5/README.md#整网运行入口) · [选点记录](../../results/tile_DSE/v5/e04_development48_250mhz_bus4_20261117/state.json)

每个候选与负载组合从派发起有 600 秒端到端时限，覆盖搜索、回放、校验和产物哈希。开发组至多并发两个任务。超时或事件额度耗尽会单独记录并占用原候选名额。已结案批次的超时项按同一名单在独立目录补测，最终完成 192/192 项。 [终态与补测记录](JOINT_SEARCH_RESULTS.md#实测覆盖与超时补测)

已结案批次的事件上限分别为 ResNet-18、ViT-B/16、VGG-16 的 800,000 和 ViT-L/16 的 1,900,000。CNN 使用全层校准，ViT 使用分层快档，每个候选与负载组合最多做 8 次详细 block 策略评价和 2 次整网策略评价。具体配置随准备清单及运行协议冻结。 [搜索方法](SEARCH_METHOD.md)
